# Pink Cloud

A 2D side-scrolling platformer developed in **Lua** using the **Defold** game engine as my A-Level Computer Science project.

The game is inspired by classic platformers such as Super Mario and uses an Alice in Wonderland-inspired setting. The player controls Cora, the Queen of Hearts, as she travels through levels, fights enemies and attempts to change history.

## Features

* 2D side-scrolling platformer gameplay
* Player movement, jumping and shooting
* Collision detection between the player, enemies, projectiles and environment
* Multiple levels
* Enemy movement, health, damage and scoring
* Player health and death system
* Scoring and progress tracking
* Temporary power-ups, including health, speed and jump boosts
* Menu, pause, game over and level completion states
* Sound effects and background music
* Animated player and game objects

## Technologies

* **Lua**
* **Defold**
* 2D game development
* Object-oriented programming concepts
* Algorithms and computational thinking
* Debugging and testing

## Development

The game was developed using a milestone-based approach. Development was divided into stages, beginning with the menu and basic level structure before adding player movement, power-ups, enemies, shooting, health, scoring, pause functionality and level completion.

The project included testing throughout development, with individual features tested as they were implemented.

## Project

This project was completed as part of my **A-Level Computer Science** coursework.

The project involved researching existing platform games, gathering user feedback, designing the game's systems and algorithms, implementing the game and evaluating the completed product.
